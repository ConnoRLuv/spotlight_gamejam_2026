# 左侧义体装备栏与悬停大图

## 行为

四个部位标题“脑机、躯干、手部、腿部”常显；每场战斗开始时卡面、装备名称和耐久为空。沿用原有义体牌出牌流程：成功支付理智、执行效果并扣除耐久后，左侧对应位置显示该义体牌的缩略卡面、完整名称和当前耐久。这里的“装备栏”展示本场已经使用的义体，初始携带装备仍由 `RunState.Loadout` 管理，不新增第二套装备或费用结算流程。

脑机需要选牌确认后才填入；取消或失败不填入。同场跨回合保留，HUD 禁用后重新启用也能从本场状态恢复；新战斗清空展示，耐久仍跨战斗保留。

悬停已填入的部位时显示放大的真实卡牌、部位名称、具体效果描述、理智费用、当前耐久、单场使用次数和同部位回合限制。空槽不会弹出窗口；移出部位后隐藏。大图只读且不拦截射线，快速切换部位时不会被旧部位的移出事件误关。耐久为 0 时保留对应卡面，详情标记“已报废”。

## 类与场景

- `BattleContext.GetUsedCyberneticCard`：查询本场对应部位最后成功使用的卡牌。记录与战斗上下文一起重建，不从初始装备直接推断展示。
- `CardPlayService`：校验成功并支付费用后记录义体牌；普通牌、功能牌、失败出牌和等待选择不会更新这份记录。
- `CyberneticEquipmentSlot`：展示一个部位的缩略卡面、名称与耐久；由 HUD 在战斗事件发生时刷新，同一卡牌不重复生成缩略图。
- `CyberneticEquipmentTooltip`：继承 `BasePanel`，共用一个悬停说明窗口。复用已有卡牌预制体，随可用区域等比调整大图，兼容 16:9 与 4:3。
- `BattleHUD.equipmentSlots`：绑定四个装备槽；HUD 解绑时清空槽与悬停说明，选择弹窗打开时关闭悬停说明。
- `Assets/Prefabs/UI/CyberneticEquipmentTooltip.prefab`：共用悬停详情预制体。

场景中 `CyberneticDurabilityArea/EquipmentSlot_0..3` 对应脑机、躯干、手部、腿部。旧色块和旧耐久文字保留引用并停用，避免破坏其他序列化引用。

## 编辑器入口

`Spotlight > Equipment > Create Slots And Wire BattleScene` 增量创建缺失的装备槽及详情预制体，并保存场景引用；有未保存的场景修改时拒绝运行。已有预制体和槽布局保留。

`Spotlight > Equipment > Validate Play Mode` 从 BattleScene 编辑模式启动，通过真实卡牌 Button 回调验证四部位、脑机取消/确认、悬停、UI 射线、耐久更新、跨回合保留、HUD 禁用/恢复及新战斗清空。仅改变运行时演示战斗，结束后退出 Play Mode，不保存运行时修改。报告和 1920×1080、1024×768 截图保存在 `Logs/Equipment`。
