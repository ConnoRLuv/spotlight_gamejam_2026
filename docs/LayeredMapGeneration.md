# 十张空白地图布局与运行时房间分配

`Assets/Prefabs/Map/Presets/Map_01.prefab` 至 `Map_10.prefab` 现为可复用的空白布局：中间节点仅保留 Node 容器和连接标记，不包含具体房间图标。只有起点与 Boss 保留固定图标。连接关系和路径保留；Map01 保留六条基础路径，其他地图保留四条。

## 新开探索

1. 从十张空白地图中随机选择一张。
2. 复制已有拓扑，用独立房间种子随机分配普通战斗、事件、精英和商店，不重新铺路或移动节点。
3. 实例化空地图，再在中间 Node 容器下实例化对应的房间预制体，并绑定点击、可达状态和玩家进度。

继续沿用房间约束：索引1固定普通战斗、索引13固定商店；精英/商店在索引5后才可出现，同类型不得连续，全局数量受限，其他房间按深度权重抽取。合法性失败仅重新分配房间，最多按配置重试，不修改布局。

## 返回与存档

同一局的完整快照保存已经分配的房间类型和探索进度。从战斗返回或恢复快照时复用这些房间，不再次随机。匹配布局时在临时 DTO 副本中忽略中间房间类型，因此不同房间分布仍能找到原来的地图预制体；不会修改源快照或布局资产。

空地图指纹只包含布局相关配置，房间权重或固定房间规则调整不需要重新烘焙地形。配置改变导致当前房间约束无法满足时显式失败，不实时铺路补救。

## 文件职责

- `MapRoomDistributor`：还原固定布局并执行原来的严格房间分配及校验。保留布局身份、节点Id和连接。
- `MapGenerationConfigAsset.LoadPreGeneratedMap(selector, roomSeed)`：默认随机选布局、随机房间种子；调试可用1..10选择布局及非零房间种子复现分布。
- `MapPresetPrefab`：保存空布局、Node容器、连接线和两个固定图标；运行时绑定独立实例。
- `MapGraphView.BindPreset`：只为缺少房间图标的容器创建对应房间子物体，居中并保持图片比例。
- `MapBlankLayoutBaker.ConvertAll`：编辑器中将既有十张地图转为空布局。原文件备份位于 `Logs/MapBlankLayouts/Before`。

十张地图统一使用230×230 Node容器，房间图标居中作为其子物体；连接线的 top/bottom/left/right 与两端 Node 的同名标记重合。Map02～Map10 已补齐对齐标准，保留原拓扑、线型与空布局。按现有线型调整行距和均匀缩放；Map02/04/05/07 在五列基准左右5个原始像素内微调节点横坐标，其余地图整列对齐。Map01未修改。MapScene 公共倍率保持36%。只有小于接入范围的图标需要等比放大以遮住真实线头；不旋转或非等比拉伸连接线。

## 验证（2026-10-17）

针对地图空布局与端点对齐的 EditMode 11/11 通过，包括十张空白层级、1000次房间分布约束/变化/确定性/快照/布局身份验证、Map01六路径、十张地图同名端点/230容器、几何及随机抽取覆盖。PlayMode 4/4 通过，包括全部十张的实际动态房间填充与两端同名标记对齐、源预制体不受污染、房间类型/位置/进度快照还原及地图→战斗→地图流程。

十张实际运行地图全部动态填充成功，源预制体均仅有两个固定图标。真实线头脱离0、线路变形0；独立读取源PNG检查全部层，十张均为线路重叠0组、无关节点矩形命中0处。布局/房间/路线数据与检查报告见 `Logs/MapBlankLayouts`。

Map02～Map10 对齐补齐的实际运行数据和 PNG 检查位于 `Logs/MapAllAnchors/Runtime`；端点最大世界坐标误差 < 0.0005，十张均无脱离和变形，PNG 非零透明像素近似栅格检查均为0线路重叠、0无关节点命中。效果图 `Logs/MapAllAnchors/map-02-aligned.png`。
