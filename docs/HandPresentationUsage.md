# 单页手牌展示

BattleHUD 保留普通牌和义体牌页签，当前页所有牌在手牌区域内居中显示，不再滚动。HandCardLayout 按真实视口等比显示卡面，牌数增加时缩小中心间距、必要时交叠；打出后其余牌自然展开，包括新世界躯干允许的超上限手牌。

界面刷新保留仍在手中的 CardView，只增删发生变化的牌。位置和尺寸用 DOTween 在 0.22 秒内过渡，悬停过渡为 0.14 秒，均使用不受时间倍率影响的时间。框内基础留白为 3 个布局单位，卡面尽量占满可用高度。默认悬停抬高 16 个布局单位，相邻牌向两侧退开 12，次邻牌退开 6；边缘额外预留让位空间避免越界。

HandCardHover 只转发指针，不处理点击、长按或出牌。普通牌或义体牌当前页不超过 7 张时，悬停只抬起当前牌，两侧保持原位；8 张及以上才启用邻牌让位。悬停按固定槽位判断，避免卡面上移后反复移入移出。开始拖拽时冻结布局并终止位置补间，结束或取消后恢复原槽位；通用 ReorderableDragList 继续供牌堆重排使用。

只在运行时接管手牌行的 LayoutGroup、ContentSizeFitter 和 ScrollRect，不更改场景、美术或通用卡牌预制体。可在 HandCardLayout 中配置留边、最大间距、抬升、让位距离和过渡时长。
