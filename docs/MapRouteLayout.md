# 地图资产接点与原尺寸布局

> 2026-10-17：当前 MapScene 已按用户要求切换为四条分层路径，总计 15 层（含 Boss），并复用节点与连接线预制体，见 [当前分层地图生成](LayeredMapGeneration.md)。本文以下记录保留的旧资产接点算法；其中“当前配置”指切换前的配置。

MapScene 使用 `MapRouteLayout.NativeSize`：路线图片与房间图标使用各自原始像素尺寸，局部缩放为 `(1,1,1)`，保留原始朝向与完整内容。图标不再统一缩为 130×130；图片和导入配置不修改。

地图为五列，相邻层只连接同列或相邻列，首领位于中列并参与同一约束搜索。当前配置启用资产接点管线，节点位置由烘焙资产几何与搜索结果确定，不再使用旧样式中的固定 230×500 网格。每条边使用一张完整连线图，不补线、不拉伸、不旋转。

节点的上、下、左、右接点由入线和出线共用，每个方向最多一条连接。先考虑同列正下方的直连，上口连接目标下口；每个节点最多三条入线，剩余斜向入线按实际资产使用左、右或下口。五种接法为上下、右下、左下、上左、上右，双轨属于同一条边，不按图片名或坐标方向猜测接法。

生成时检查所有非零透明度的原图像素，包含圆环和短支线；共同端点的中心接入内核允许接合，其余区域禁止线路重叠、相邻接触或穿过无关节点。无关节点按所有图标中最大的原尺寸矩形保守避让，当前为 269×269；中心接入内核仍为 130×130，避免改变已校准的线头。

基础路线按不同目标节点随机选择左右或同列推进，多列且层数足够时至少包含两次跨列移动；同列直连不再始终排在候选方向首位。方向先随机、再尝试对应原图摆放，避免某方向的模板数量较多而获得额外权重。同列正下方连入仍须先占下侧，这与路线是否优先直走是两件事。

新增分支的起始深度分散到整张地图，并在各深度区间内随机选择；先沿已有路径抵达对应深度，再增加分支。每条支路优先按随机三至六条边寻找合流，合流目标也随机排序；未到偏好长度时先尝试延伸，到达后先尝试合流。几何受限时可以回溯，允许更早或更晚合流，但至少经过两个独立节点，即至少三条边后才允许合流。持续并行的支路和左右转向都视为有效变化，不要求每一层都新增岔路。仍满足原有连通性、最低路径数和房间规则；失败时回溯或重试，不能展示非法地图。固定候选与节点的几何检查在一次搜索中缓存，避免回溯反复扫描同一组像素。

当前 MapScene 按原图尺寸预览：`MapGraphView → Style → Background Width Ratio = 0`、`Display Scale = 1`，公共地图容器不额外缩放。地图较长，通过滚动浏览。背景保持原宽高比，底纹铺放方式见下文。

`Background Width Ratio` 为 `0` 时使用 `Display Scale` 固定倍率。需要恢复参考图的整体比例时可设为 `0.65`，使底板宽度占背景实际显示宽度的 65%；窗口尺寸变化时自动保持比例，兼容其他场景。

底纹按确认使用单张图片拉伸铺满整个地图区域，UV 固定为 `(0,0,1,1)`，不再横向或纵向重复。该拉伸仅作用于底纹，节点和连线仍保持原始比例；原图及导入配置不修改。旧 `BackdropTileScale` 字段仅保留配置兼容，不再影响显示。

滚轮上下浏览，Shift＋滚轮横向浏览；进入节点时自动滚动到对应位置。滚动范围按缩小后的实际内容计算，Canvas 原有的分辨率适配机制保持不变。

替换线路后运行 `Spotlight → Map → Bake Asset Constrained Routes`，从源 PNG 烘焙接点与像素行程；不需要修改纹理 Read/Write 开关。当前工具只更新 `Assets/GameData/Map/MapGenerationConfig.asset`。接点分组取实体线芯，碰撞掩码仍包括抗锯齿边缘的全部非零透明度像素。

已生成的布局随 `AdventureSession` 保留；完整快照保存节点身份、实际坐标、接点和图片位置，不在切换场景时重算。旧的仅种子快照仍用旧生成管线恢复，不自动迁移为新拓扑。重新烘焙或修改约束只影响之后生成的地图。

`Repair Route Connections` 保留用于旧模式端点校准；新约束地图的位置以烘焙配置为准。新增或替换图后应运行资产约束烘焙工具。

旧 `RotateToFit`、`NativeFit`、`SimpleStretch` 枚举值保留，兼容其他场景；MapScene 不使用这些缩放模式。
